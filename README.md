# BusDirect-Brief2
Gestion des trajets

Description

Ce projet consiste à récupérer les données des trajets depuis un fichier trips.json et à les afficher dynamiquement sur la page principale index.html.

Fonctionnalités

* Récupération des données avec fetch().
* Lecture des données JSON avec .json().
* Affichage dynamique des trajets sur la page index.html.
* Utilisation du JavaScript DOM pour générer les éléments HTML.

Technologies utilisées

* HTML
* CSS
* JavaScript
* Fetch API
* JSON
