BusDirect

BusDirect est une application web qui permet de consulter les trajets de bus et de gérer les réservations.

Fonctionnalités

* Afficher la liste des trajets.
* Rechercher et filtrer les trajets.
* Naviguer entre les pages avec la pagination.
* Réserver un siège.
* Modifier ou supprimer une réservation.
* Afficher les sièges disponibles et occupés.
* Sièges VIP (1 à 4) avec un supplément de 10 %.
* Vérifier les numéros de téléphone marocains.
* Sauvegarder les données avec LocalStorage.

Technologies utilisées

* HTML
* CSS / Tailwind CSS
* JavaScript
* JSON
* LocalStorage
